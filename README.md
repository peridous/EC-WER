Official implementation of **“Consequence Distillation for Transferable Automatic Speech Recognition Evaluation.”**

**Michael Wang** and **Seong Jong Yoo**

This repository contains the code and evaluation scripts for consequence distillation in automatic speech recognition (ASR) evaluation.

We study consequence at two granularities:

* **Direct Estimate:** transcript-level prediction of downstream task failure.
* **EC-WER:** edit-level consequence estimation that attributes downstream impact to individual substitutions, deletions, and insertions while retaining conventional WER structure.

Code, evaluation scripts, and reproduction instructions will be released here.
